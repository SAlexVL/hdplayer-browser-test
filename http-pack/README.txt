Загрузка на хостинг animal-park.by для LED (обход проблемы HTTPS)

1. По FTP/файловому менеджеру создайте каталог в корне сайта:
   /led/
2. Загрузите в него этот index.html как ЕДИНЫЙ файл.
   Не создавайте страницу через админку MODX — иначе подтянется шаблон сайта.
3. В HDPlayer укажите программу «Веб-страница» / HTML с адресом:
   http://animal-park.by/led/
   именно HTTP, не HTTPS.
4. Если снова белый экран — контроллер, возможно, уже запомнил HSTS
   или хостинг принудительно режет HTTP. Тогда оставьте контент на:
   https://salexvl.github.io/hdplayer-browser-test/
5. Долгосрочное решение на сервере: сертификат Let's Encrypt
   (цепочка до ISRG Root X1), либо другой CA, которому доверяет
   старый Android WebView контроллера HD-A3L.
