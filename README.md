# Диагностика браузера экрана HDPlayer

Одна страница без внешних библиотек и сетевых запросов. Её открывают на плеере LED-экрана, чтобы увидеть версию браузера, строку User-Agent и набор базовых возможностей.

Страница рассчитана на кадр 896×576 и сама масштабируется под размер окна. Две карточки сменяются каждые 20 секунд. Пробел или кнопка «Пауза» останавливают смену, стрелки и кнопка «Далее» переключают карточку. Адрес с `?page=1` или `?page=2` закрепляет одну карточку.

Публикация — GitHub Pages из корня ветки `main`. Файл `.nojekyll` отключает обработку Jekyll.
